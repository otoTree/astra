# ADR-0010：平台自管理管理员身份

## 状态

已采纳。

## 决策

管理台不接入 OIDC 或其他外部身份提供方。Astra 在 PostgreSQL 保存平台管理员账号、Argon2id 密码哈希、组织/项目绑定和失败锁定状态；登录接口为 `POST /admin/v1/sessions/login`。登录成功后继续使用 HttpOnly Session Cookie、独立 CSRF Cookie、RBAC 和审计。

`ADMIN_BOOTSTRAP_*` 环境变量只负责首次创建超管账号。初始化采用“存在则不覆盖”语义，密码不会写入日志、审计详情、响应或镜像；初始化完成后应移除 bootstrap 密码变量，密码变更通过后续管理接口或受控运维流程完成。

## 原因

内部平台需要独立、可审计、可在无外部身份服务的环境启动。将权限、项目绑定和锁定策略置于平台数据库，避免开发、隔离测试和生产依赖额外身份服务，同时不改变已稳定的 Session/CSRF/RBAC 边界。

## 后果

- 必须保护管理员密码变量和数据库哈希，并执行失败锁定、轮换和审计。
- 组织/项目成员关系使用 `local_user` subject 类型；旧 OIDC 数据仅作为历史兼容记录，不参与新的登录路径。
- Compose 和 Helm 不再启动或配置身份提供方。
